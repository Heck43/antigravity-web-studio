# 🎨 Recommended Design & CSS Inspiration Sources

A curated list of top-tier resources for agents to search and reference when planning UI/UX, styling, CSS components, and color schemes.

---

## 1. Real Product UI/UX Patterns (Компоновка, экраны, структура)
- **Mobbin** (`https://mobbin.com`) — Industry standard for real-world web/mobile UI patterns, navigation flows, and screen hierarchies.
- **Refero** (`https://refero.design`) — Curated collection of real SaaS web application screens, dashboards, modals, settings, and table views.
- **Godly** (`https://godly.website`) — Modern, aesthetically driven web design inspiration with micro-interactions and contemporary typography.
- **Dribbble** (`https://dribbble.com/tags/web-design`) & **Behance** (`https://www.behance.net`) — Creative visual concepts, dashboard cards, and widget ideas.

---

## 2. Component Systems & Ready-Made CSS (Готовые компоненты и чистый CSS)
- **Uiverse.io** (`https://uiverse.io`) — Huge open-source library of community-made UI elements in pure HTML & CSS: buttons, card hover effects, inputs, checkboxes, toggles, loaders, and tooltips.
- **HyperUI** (`https://www.hyperui.dev`) — Free open-source Tailwind CSS components: application headers, stats grids, form groups, modals, and tables.
- **Shadcn UI** (`https://ui.shadcn.com`) — The gold standard of modern component aesthetics: clean border radiuses, subtle borders, high contrast, accessible Radix-based patterns.
- **Modern CSS Solutions** (`https://moderncss.dev`) — Production CSS patterns using CSS Grid, Flexbox, custom properties, and subgrid without framework overhead.

---

## 3. Color Palettes & Contrast (Цветовые палитры и токены)
- **Realtime Colors** (`https://realtimecolors.com`) — Real-time testing of palettes (Primary, Secondary, Accent, Neutral, Background) directly on a simulated webpage.
- **Coolors** (`https://coolors.co`) — Color palette explorer and contrast checker (WCAG compliance).
- **Tailwind Color System** (`https://tailwindcss.com/docs/customizing-colors`) — Battle-tested 50–950 shade steps (Slate, Indigo, Emerald, Amber, Rose) ideal for dark & light UI themes.

---

## 4. Modern Icons (Открытые иконки)
- **Lucide Icons** (`https://lucide.dev/icons`) — Clean, consistent, lightweight SVG icons (standard for modern web apps).
- **Tabler Icons** (`https://tabler.io/icons`) — Over 5,000 free, customizable vector icons.
- **Heroicons** (`https://heroicons.com`) — Handcrafted SVG icons by the creators of Tailwind CSS.

---

## 5. Typography Pairings (Шрифты)
- **Interface Workhorses:** `Inter`, `Plus Jakarta Sans`, `DM Sans`, `Outfit`, `Geist`.
- **Display & Headings:** `Space Grotesk`, `Cabinet Grotesk`, `Syne`.
- **Code & Monospace:** `JetBrains Mono`, `Fira Code`.
