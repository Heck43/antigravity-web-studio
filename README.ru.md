# Antigravity Web Product AI Studio

<p align="center">
  <a href="README.md">English Version</a> &bull; <b>Русская версия</b>
</p>

> **Автономная инженерная среда для разработки веб-приложений с помощью AI-агентов (Antigravity 2.0, Claude Code, Cursor, Codex, Gemini CLI).**

Создавайте оригинальные, проверенные и готовые к использованию веб-приложения с нуля без ручного копирования кода и конфликтов контекста.

---

## Ключевые возможности

- **Мультипроектная изоляция (`apps/<slug>/`):**  
  Разрабатывайте несколько веб-приложений параллельно в одной рабочей среде. У каждого проекта — собственный код, стили и личная документация (`docs/`). Завершенные проекты изолированы и никогда не затираются новыми запусками.
- **5-фазный инженерный протокол разработки:**  
  1. **Анализ и изоляция (Think & Isolate):** Декомпозиция задач, определение сценариев использования и клонирование чистых шаблонов в `apps/<slug>/docs/`.
  2. **Интерактивные вопросы по дизайну (`ask_question`):** Агент уточняет у вас желаемую расстановку блоков, тему оформления и структуру интерфейса через интерактивное меню перед версткой.
  3. **Обязательный поиск дизайна:** Проверка современных UI-паттернов, цветовых палитр и типографики по проверенным источникам (`knowledge/design-sources.md`).
  4. **Работа напрямую в файлах (Zero Code in Chat):** Весь код создаётся сразу в файлах проекта на диске — никакого замусоривания чата длинными простынями кода.
  5. **Автоматическая верификация и Pre-Release Lint:** Проверка синтаксиса через Node.js (`node -c`), тесты и запуск линтера качества перед сдачей работы.
- **База готовых рецептов ([knowledge/](knowledge/)):**  
  Проверенные решения для сохранения состояния в `localStorage`, доступных модальных окон (WAI-ARIA Focus Trap), адаптивных дизайн-токенов и стилей.
- **Встроенный чекер качества ([scripts/web-lint.js](scripts/web-lint.js)):**  
  Автоматическая проверка проекта перед сдачей (doctype, viewport, скобки CSS, синтаксис JS, проверка на забытые токены и дебаг-код).
- **Поддержка любых фреймворков и стеков:**  
  Чистый **HTML5 / CSS3 / Vanilla JS**, а также автоматическое развертывание **React**, **Vue 3**, **Svelte**, **Tailwind CSS** и **TypeScript** через Vite и npm.

## Быстрый старт

### 1. Откройте папку в Antigravity или другом AI-редакторе
Откройте корневую папку в **Antigravity 2.0**, **Cursor**, **Claude Code** или **Gemini CLI**.

### 2. Задайте агенту задачу
Просто опишите, что нужно создать, и укажите имя папки:

#### Пример 1: Чистый веб (Vanilla JS)
> *"Создай в папке `apps/crypto-dashboard` веб-приложение: мониторинг цен криптовалют с интерактивными графиками, поиском и списком избранного на чистом JS/CSS."*

#### Пример 2: React + Tailwind CSS
> *"Создай в папке `apps/kanban-board` приложение на **React + Tailwind CSS** через Vite: канбан-доска с drag-and-drop карточек, модальным окном создания задач и сохранением в localStorage."*

#### Пример 3: Vue 3
> *"Создай в папке `apps/recipe-book` приложение на **Vue 3**: каталог кулинарных рецептов с фильтрами по ингредиентам и таймером готовки."*

## Контроль качества (Pre-Release Lint)

Перед сдачей или публикацией любого приложения запустите проверку:

```bash
node scripts/web-lint.js apps/<имя-приложения>
```

Проверяет:
- Наличие и корректность структуры `index.html` (doctype, viewport, title);
- Парность фигурных скобок во всех `.css` файлах;
- Синтаксическую валидность JavaScript через Node.js;
- Сканирует код на случайные токены и забытые `debugger;`.
