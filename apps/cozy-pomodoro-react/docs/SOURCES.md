# Research & Sources — Cozy Focus (:3)

## 1. Web Research & Inspiration
- **Aesthetic Inspiration:** Lofi study timers (Flocus, Lofi.co, Pomofocus, Aesthetic Pomodoro UI on Dribbble & Behance).
- **Color Palettes:** Pastel Kawaii color harmony (warm cream `#FFF8F6`, blush pink `#F472B6`, pastel mint `#34D399`, lavender `#A78BFA`).
- **Sound Architecture:** Procedural Web Audio API sound synthesis (white/pink noise filtering for rain/wind, pulse oscillators for crackle) to ensure offline availability without external audio hosting dependencies.

## 2. Dependencies
- React 19 (`react`, `react-dom`): Declarative state, hooks, component composition.
- Vite 6: Fast modern bundler and development server.
- Lucide React (`lucide-react`): Consistent clean line icons.
- Canvas Confetti (`canvas-confetti`): Lightweight celebration particle bursts on session completion.
