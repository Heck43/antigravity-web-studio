# Cozy Focus & Pomodoro (:3) — Product Brief

## 1. Vision & Concept
«Cozy Focus» — это нежное, тёплое и эстетичное React-приложение для концентрации, учёбы и отдыха. Оно объединяет классический Pomodoro-таймер с кавайным интерактивным персонажем-помощником, генератором расслабляющих фоновых звуков природы/уюта (Web Audio API), списком маленьких приятных дел и трекером настроения.

## 2. Target Audience & Vibe
- Пользователи, которые любят эстетику cozy/lo-fi/kawaii, пастельные тона, мягкие микроанимации и добрую поддержку без стресса дедлайнов.
- Студенты, разработчики, дизайнеры и творческие люди, которым нужен уютный компаньон во время работы.

## 3. Core Features
1. **Интерактивный Pomodoro-таймер:**
   - Режимы: Фокус (по умолчанию 25 мин), Короткий перерыв (5 мин), Длинный перерыв (15 мин).
   - Круговой визуальный индикатор прогресса (SVG circular track & glow).
   - Кнопки управления (Старт / Пауза / Сброс / Пропуск) и счётчик завершённых сессий (томатов/сердечек).
   - Мягкий гармоничный звук гонга/колокольчика (синтезирован через Web Audio API, надёжно работает без интернета).
   - Конфетти-салют при завершении помидорки (canvas-confetti).
2. **Живой интерактивный маскот (Котик «Моти» :3):**
   - SVG-анимации состояний:
     - Во время фокуса: внимательно читает/работает с мягким покачиванием и морганием.
     - Во время перерыва: пьёт тёплый чай/какао с паром.
     - На паузе: сладко спит с «Zzz».
     - При завершении: радостно ликует с сердечками!
   - Клик по котику выдаёт милые ободряющие фразы.
3. **Генератор расслабляющих фоновых звуков (Cozy Ambient Sounds):**
   - 4 аудио-режима на базе Web Audio API (Rain / Дождь за окном, Campfire / Уютный камин с потрескиванием, Coffee Shop / Кофейный гул, Breeze / Нежный ветерок).
   - Независимые ползунки громкости и быстрое включение/отключение.
4. **Список задач («Маленькие шаги»):**
   - Быстрое добавление задач с оценкой в помидорках.
   - Завершение, удаление, сохранение состояния в `localStorage`.
5. **Трекер настроения и вдохновляющие цитаты:**
   - Выбор настроения дня с милыми эмодзи.
   - Случайные тёплые вдохновляющие подсказки.
6. **Настройки таймера:**
   - Доступное модальное окно для настройки длительностей фокуса и перерывов, переключения звуков.

## 4. Technical Stack
- React 19 + Vite
- Lucide React (иконки)
- Canvas-confetti (праздничные эффекты)
- Web Audio API (чистый процедурный звук колокольчика и ambient шума без тяжелых аудиофайлов)
- CSS3 Custom Properties (пастельная дизайн-система, flexbox/grid, keyframe-анимации)
