# Implementation Plan: Менеджер учебных задач

## Архитектура и этапы разработки

### Этап 1: Исследование и дизайн-система (Research & Design Tokens)
- [x] Определение цветовой палитры: глубокий индиго/ультрамарин как основной оттенок студенческого фокуса (`#4F46E5`), изумрудный для выполненных (`#10B981`), янтарь для среднего приоритета (`#F59E0B`), кораллово-красный для высокого приоритета и просроченных (`#EF4444`).
- [x] Документирование токенов в `docs/DESIGN.md` и ссылок в `docs/SOURCES.md`.

### Этап 2: Семантическая верстка (`project/index.html`)
- [x] Шапка приложения с заголовком, текущей датой и быстрым статусом.
- [x] Блок аналитики/статистики (Всего, Выполнено, В процессе, Прогресс-бар).
- [x] Форма быстрого добавления задачи (название, описание, приоритет, дедлайн, кнопки).
- [x] Панель инструментов: поиск, фильтры в виде табов/чипсов, селектор сортировки.
- [x] Список задач (`<ul role="list">`) с поддержкой пустого состояния (Empty State).
- [x] Модальное окно редактирования задачи с фокусом и доступностью.
- [x] Всплывающие уведомления (Toasts) для обратной связи.

### Этап 3: Стилизация и адаптивность (`project/style.css`)
- [x] CSS Custom Properties для дизайн-токенов (цвета, шрифты, отступы, тени, радиусы).
- [x] Карточки задач со статусными индикаторами приоритета и дедлайнов.
- [x] Аккуратные бейджи (`Низкий`, `Средний`, `Высокий`, `Просрочено`, `Готово`).
- [x] Адаптивная сетка (Grid / Flexbox) для мобильных телефонов (320px-600px), планшетов и десктопов.
- [x] Микро-анимации при добавлении, завершении и удалении.

### Этап 4: Логика JavaScript (`project/script.js`)
- [x] Модель данных `Task`: `{ id, title, description, priority, dueDate, completed, createdAt, updatedAt }`.
- [x] Модуль `StorageManager` с `localStorage` сериализацией, валидацией и дефолтными учебными задачами.
- [x] Модуль фильтрации (`all`, `active`, `completed`, `high`) и поиска.
- [x] Модуль сортировки (`dueDate-asc`, `dueDate-desc`, `priority-desc`, `createdAt-desc`).
- [x] Калькулятор статистики (вычисление total, completed, active, percentage).
- [x] Обработчики событий (добавление, валидация, редактирование, удаление, смена статуса).

### Этап 5: Верификация, QA и сдача
- [x] Синтаксическая проверка JS (`node -c`).
- [x] Тестирование в реальном браузере / headless скриптом всех сценариев.
- [x] Создание корневого хаба и отчет `docs/RESULT.md`.
