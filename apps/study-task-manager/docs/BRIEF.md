# Product Brief: Менеджер учебных задач (Study Task Manager)

## Цель проекта
Разработка современного, отзывчивого и удобного веб-приложения для управления учебными задачами студентов и школьников с сохранением в `localStorage`, продвинутой фильтрацией, сортировкой, детальной статистикой и адаптивным интерфейсом для мобильных устройств и десктопа.

## Технологический стек
- HTML5 (семантическая разметка, ARIA-атрибуты, валидные формы без перезагрузки)
- CSS3 (CSS Custom Properties, Flexbox & Grid, адаптивный дизайн mobile-first, плавная анимация micro-interactions)
- Чистый JavaScript ES6+ (модульная архитектура, localStorage, CRUD-операции, вычисляемая статистика, фильтрация и сортировка)

## Основные функциональные требования
1. **Создание задач**:
   - Название (обязательное поле с валидацией)
   - Подробное описание
   - Уровень приоритета (Низкий, Средний, Высокий с визуальными цветовыми индикаторами)
   - Срок сдачи (Дедлайн: дата и время с индикатором просрочки/срочности)
2. **Управление задачами**:
   - Переключение статуса выполнения (чекбокс с зачеркиванием и визуальным переходом)
   - Редактирование существующей задачи (модальное окно с предзаполнением)
   - Удаление задачи с возможностью быстрого подтверждения/отмены
3. **Фильтрация и поиск**:
   - «Все» (All)
   - «Активные» (In Progress)
   - «Выполненные» (Completed)
   - «С высоким приоритетом» (High Priority)
   - Живой поиск по названию и тексту описания
4. **Статистика в реальном времени**:
   - Всего задач (Total)
   - Выполнено (Completed)
   - В процессе (In progress)
   - Прогресс-бар выполнения задач в процентах
5. **Сортировка**:
   - По сроку выполнения (сначала ближайшие дедлайны)
   - По сроку выполнения (сначала дальние дедлайны)
   - По приоритету (Высокий -> Средний -> Низкий)
   - По дате создания (новые сначала / старые сначала)
6. **Персистентность (localStorage)**:
   - Сохранение всех изменений без перезагрузки страницы
   - Предзаполнение демонстрационными студенческими задачами при первом входе
7. **Адаптивность и мобильный интерфейс**:
   - Тач-френдли контролы (минимальная высота тапа 44px)
   - Оптимизированная верстка для экранов от 320px до 1440px+
   - Быстрый доступ к добавлению задач
