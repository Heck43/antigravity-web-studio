# Отчет о сдаче проекта: «Менеджер учебных задач»

## 1. Выполненные требования
Приложение разработано на чистом стеке **HTML5 + CSS3 + Vanilla JavaScript (ES6+)** в структуре `project/`:
- [x] **Добавление задач**:
  - Название (обязательное с валидацией);
  - Описание (многострочный текст);
  - Приоритет: Низкий / Средний / Высокий (с цветовыми бейджами и акцентными полосами);
  - Срок выполнения (валидный инпут даты, вычисление статуса: Сегодня, Завтра, Осталось X дн., Просрочено).
- [x] **Управление задачами**:
  - Отметка задачи как выполненной (чекбокс с зачеркиванием текста и плавным изменением прозрачности);
  - Удаление (кнопка удаления с обновлением статистики и уведомлением);
  - Редактирование (модальное окно с предзаполнением всех полей и валидацией).
- [x] **Фильтрация задач**:
  - Все (All);
  - Активные (Active);
  - Выполненные (Completed);
  - С высоким приоритетом (High Priority);
  - Дополнительно: мгновенный поиск по подстроке в названии или описании.
- [x] **Статистика в реальном времени**:
  - Всего задач;
  - Выполнено;
  - В процессе (активные);
  - Наглядный процентный индикатор и прогресс-бар.
- [x] **Сохранение данных (localStorage)**:
  - Автоматическое сохранение всех изменений в `localStorage`;
  - Данные не исчезают после обновления страницы;
  - Предзаполнение 4 реалистичными учебными задачами при первом открытии.
- [x] **Дополнительные возможности**:
  - Сортировка: по ближайшему дедлайну, по дальнему дедлайну, по приоритету (высокий → низкий), по дате добавления;
  - Адаптивный интерфейс для смартфонов и планшетов (брейкпоинты 600px и 900px, тач-таргеты от 44px);
  - Всплывающие информационные тосты (Toasts);
  - Очистка ошибок при вводе и закрытие модалки по клавише `Escape` и клику на подложку;
  - Полноценная SPA-логика без перезагрузки страницы (`e.preventDefault()`).

## 2. Структура созданных файлов
- [`project/index.html`](./project/index.html) — семантическая разметка, ARIA-атрибуты, карточки статистики, форма добавления, список задач и модальное окно.
- [`project/style.css`](./project/style.css) — современная дизайн-система на CSS Custom Properties, адаптивная сетка, бейджи приоритетов и адаптация под мобильные устройства.
- [`project/script.js`](./project/script.js) — независимая модульная JS-логика без фреймворков и библиотек.
- [`index.html`](./index.html) — корневой шлюз для автоматического запуска.
- [`scripts/verify-task-manager.js`](./scripts/verify-task-manager.js) — скрипт автоматической верификации.
- Документация:
  - [`docs/BRIEF.md`](./docs/BRIEF.md)
  - [`docs/PLAN.md`](./docs/PLAN.md)
  - [`docs/DESIGN.md`](./docs/DESIGN.md)
  - [`docs/SOURCES.md`](./docs/SOURCES.md)

## 3. Проведенное тестирование
1. Синтаксическая валидация JavaScript через `node -c project/script.js` — ошибок нет (код 0).
2. Автоматическое тестирование через `node scripts/verify-task-manager.js` — все 15 критических DOM-селекторов, 4 фильтра, CSS-переменные, адаптивные медиазапросы, CRUD, расчет статистики и сохранение в localStorage прошли проверку на 100%.
3. Проверена работа формы без перезагрузки страницы (SPA).
