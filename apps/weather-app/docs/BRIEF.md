# Product Brief: Aura Weather (Атмосфера)

Status: READY_FOR_BUILD

## Idea
Полнофункциональное, современное и эстетичное веб-приложение погоды ("Aura Weather / Атмосфера") с живым прогнозом через надежное бесплатное API (Open-Meteo), вдохновленное дизайном Apple Weather и Linear. Приложение предоставляет детальный текущий прогноз, почасовой прогноз на 24 часа, 7-дневный прогноз с графическими шкалами температур, параметры атмосферы (ветер, давление, УФ-индекс, влажность, восход/закат) и умный поиск городов с автодополнением и сохранением избранного.

## Goal
Создать премиальный, удобный и быстрый погодный интерфейс без необходимости ввода API-ключей пользователем, работающий мгновенно, адаптивный для мобильных и десктопных экранов.

## Target User
Пользователи, которым нужен точный, красивый и информативный прогноз погоды для своего города или путешествий с поддержкой русского и английского языков.

## Primary Journey
1. Открытие приложения: автоматическое определение геолокации или запуск с дефолтным городом (Москва / сохраненным городом).
2. Просмотр текущей погоды: анимированный атмосферный градиент, температура, "ощущается как", статус WMO, максимум/минимум.
3. Анализ 24-часового прогноза (горизонтальный скролл с иконками и вероятностью осадков).
4. Просмотр 7-дневного прогноза с полосами температурного диапазона.
5. Изучение детальных карточек: УФ-индекс, влажность, давление (в мм рт. ст. и hPa), ветер с компасом, восход/закат.
6. Поиск любого города мира через строку с автодополнением, добавление в избранное, переключение единиц измерения (°C/°F, км/ч / м/с).

## Must-have Features
- 100% рабочее надежное API (Open-Meteo Forecast & Geocoding API).
- Автодополнение поиска городов по всему миру (на русском и английском).
- Определение текущей локации по кнопке "Мое местоположение" (Geolocation API).
- Избранные города с сохранением в `localStorage`.
- Почасовой прогноз на 24 часа и 7-дневный прогноз.
- Блоки детальной погоды (Ветер, Влажность, УФ, Давление, Видимость, Восход/Закат).
- Переключение единиц: °C / °F, мм рт. ст. / hPa, км/ч / м/с.
- Переключение языка: Русский / English.
- Динамический фон в зависимости от времени суток и погоды (день, ночь, дождь, снег, гроза, облачность).
- Полная адаптивность (Mobile, Tablet, Desktop).

## Non-goals
- Платные провайдеры погоды, требующие регистраций и кредитных карт.
- Серверный бэкенд (приложение работает автономно на стороне клиента).

## Assumptions
- У пользователя есть доступ в интернет для запросов к api.open-meteo.com.
- Современный браузер с поддержкой CSS Grid, Flexbox, Fetch API, LocalStorage.

## Acceptance Criteria
- [x] Поиск городов возвращает актуальные результаты с координатами и страной.
- [x] Загрузка погоды отображает корректные текущие данные, 24 часа и 7 дней.
- [x] Переключение единиц измерения пересчитывает все отображаемые значения.
- [x] Добавление/удаление городов из избранного работает и сохраняется между перезагрузками.
- [x] Интерфейс имеет премиальный стеклянный стиль (glassmorphism), адаптивную сетку и доступные элементы управления.
