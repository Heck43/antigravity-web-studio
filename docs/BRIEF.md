# Product Brief: Менеджер учебных задач (Study Task Manager)

Status: IN PROGRESS

## Idea
Разработка веб-приложения для управления учебными задачами (курсовые, домашние задания, лабораторные, подготовка к экзаменам) на чистом стеке HTML5 + CSS3 + vanilla JavaScript без перезагрузки страниц и сторонних фреймворков.

## Goal
Создать удобный, современный, адаптивный инструмент для студентов и учащихся, позволяющий организовать учебный процесс, контролировать дедлайны и отслеживать прогресс выполнения заданий с сохранением данных в браузере (`localStorage`).

## Target user
Студенты вузов и колледжей, школьники, слушатели курсов, которым необходим быстрый персональный трекер учебных дедлайнов с разделением по приоритетам и статусам.

## Primary journey
1. Пользователь заходит в приложение и видит текущие задачи, обзор дедлайнов и сводку статистики (Всего задач, Выполнено, В процессе, шкала прогресса).
2. Заполняет форму новой учебной задачи: название предмета/задания, подробное описание, приоритет (Низкий, Средний, Высокий) и дату сдачи (дедлайн).
3. Добавляет задачу нажатием кнопки или по клавише — задача мгновенно появляется в списке с анимацией и подсветкой статуса.
4. Отмечает выполненные задачи кликом по чекбоксу — карточка задачи меняет стиль, счётчики и прогресс-бар моментально пересчитываются.
5. Фильтрует задачи по вкладкам: «Все», «Активные», «Выполненные», «С высоким приоритетом», а также может искать по названию/описанию.
6. Сортирует список по сроку сдачи (сначала горящие дедлайны) или по приоритету (от критических к обычным).
7. При необходимости редактирует задачу через модальное окно или удаляет её с подтверждением.
8. Все изменения автоматически сохраняются в `localStorage` и восстанавливаются при обновлении страницы.

## Must-have features
- [x] Форма добавления задачи:
  - Название (обязательное, валидация);
  - Описание (многострочное, опциональное);
  - Приоритет (низкий / средний / высокий) с цветовой кодировкой;
  - Срок выполнения (input date с валидацией).
- [x] Управление задачами:
  - Переключение статуса «выполнено / активно»;
  - Редактирование всех параметров задачи;
  - Удаление задачи;
  - Быстрое восстановление / удаление.
- [x] Фильтрация:
  - Все задачи;
  - Только активные;
  - Только выполненные;
  - С высоким приоритетом.
- [x] Статистика в реальном времени:
  - Всего задач;
  - Выполнено;
  - В процессе (активных);
  - Процент выполнения и интерактивный прогресс-бар.
- [x] Сохранение в `localStorage`:
  - Загрузка при старте;
  - Синхронизация при любых мутациях;
  - Защита от повреждённых данных в хранилище.
- [x] Дополнительные возможности:
  - Сортировка по сроку сдачи (возрастание / убывание);
  - Сортировка по приоритету (высокий -> низкий);
  - Поиск в реальном времени;
  - Адаптивный дизайн (Mobile 360px+ / Tablet 768px / Desktop 1200px+);
  - Стартовый набор реалистичных учебных задач (demo data) при первом входе или по кнопке сброса.

## Non-goals
- Серверная авторизация и бэкенд-база данных (строго клиентское приложение по ТЗ).
- Сторонние JS-библиотеки (React, jQuery, Bootstrap JS) — реализация на чистом JS.

## Assumptions
- Пользователь работает в современном браузере с поддержкой ES6+ и `localStorage`.
- Дата дедлайна хранится в формате ISO `YYYY-MM-DD`.

## Acceptance criteria
- [ ] Приложение работает полностью без перезагрузки страниц (SPA).
- [ ] Все пункты ТЗ (добавление, редактирование, удаление, чекбокс, 4 фильтра, 3 счётчика, сортировка, localStorage, адаптив) реализованы и работают стабильно.
- [ ] Присутствуют визуальные состояния: пустой список (empty state), подсветка просроченных дедлайнов (overdue), дедлайны «сегодня / завтра».
- [ ] Доступность (a11y): семантические теги, управление с клавиатуры (Esc для модалки, Enter для отправки), aria-атрибуты.
- [ ] Интерфейс адаптивен и корректно отображается на экранах телефонов (360px - 480px), планшетов и десктопов.
- [ ] Полный комплект файлов в папке `project/` (`index.html`, `style.css`, `script.js`).
