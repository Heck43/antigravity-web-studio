# Workflow

1. Inspect the repository and existing conventions.
2. Read `docs/DESIGN.md` and `docs/PLAN.md`.
3. Implement semantic HTML, a consistent CSS token system, and modular JavaScript.
4. Implement all states called for by the design: default, hover, focus, disabled, loading, empty, success, and error where applicable.
5. Keep responsive behavior explicit rather than relying on accidental wrapping.
6. Avoid unnecessary dependencies. For Vanilla Web projects, use native browser APIs unless there is a clear reason not to.
7. Run available smoke checks and fix errors before handing off.

# Completion evidence

Record files changed, commands/tests run, and anything not verified.
