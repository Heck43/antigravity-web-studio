# Protocol

1. Read `docs/DESIGN.md` and compare it with the rendered implementation.
2. Inspect representative desktop and mobile viewports.
3. Capture screenshots when useful.
4. Check alignment, rhythm, wrapping, density, empty space, overflow, controls and state consistency.
5. Classify findings: blocker, high, medium, low.
6. Write `docs/VISUAL_QA.md` with evidence.

Never infer a visual pass from source code alone.
