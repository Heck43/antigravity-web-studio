# Principles

Treat references as a dataset, not a template. Combine patterns from multiple products and introduce original composition, content hierarchy, and visual language.

# Output

Document:
- product personality;
- design principles;
- color tokens;
- typography scale;
- spacing/radius/shadow rules;
- grid/container behavior;
- component inventory;
- screen-by-screen structure;
- states and interactions;
- responsive behavior;
- accessibility requirements.

Write to `docs/DESIGN.md` and optionally `artifacts/research/DESIGN_DIRECTION.md`.
