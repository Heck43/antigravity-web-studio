# Gate

PASS only when:
- acceptance criteria have evidence;
- primary flow works;
- required responsive views have been inspected;
- console/runtime errors are understood;
- blocker/high defects are resolved or explicitly blocked;
- release artifacts are complete;
- run instructions are known.

Otherwise mark the gate BLOCKED and name the exact reason.
