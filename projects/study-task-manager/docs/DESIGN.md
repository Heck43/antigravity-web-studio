# Design Direction: «Менеджер учебных задач»

## Visual concept
Стильный, современный и чистый веб-интерфейс в академическом стиле «Modern Campus Productivity». Основной упор сделан на контрастность, читаемость учебных данных, быстрое визуальное сканирование сроков сдачи и мотивирующую шкалу прогресса.

## Layout & grid
- **Макро-структура**:
  - `Header`: логотип, название сервиса, краткий слоган, кнопка быстрой перезагрузки учебных примеров.
  - `Stats-bar`: сетка из 4 карточек метрик (Всего задач, Выполнено, В процессе, Прогресс в % со шкалой) с поддержкой CSS Grid (`repeat(auto-fit, minmax(220px, 1fr))`).
  - `Main-layout`: асимметричная 2-колоночная сетка:
    - Слева (360px–380px): липкая (sticky) панель создания задачи с валидируемой формой.
    - Справа (1fr): панель инструментов (живой поиск, фильтры-табы, селектор сортировки) и список задач.
- **Мобильный макет (< 880px)**:
  - Плавное переключение в 1-колоночный поток: карточки статистики в 2 колонки, затем форма добавления, затем панель инструментов и список задач.
  - Полноэкранное или компактное модальное окно на экранах < 600px.

## Typography
- Семейство: `'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Helvetica, Arial, sans-serif`.
- Иерархия:
  - Заголовок H1 (App Title): 1.625rem (26px), SemiBold 700.
  - Заголовки карточек H2: 1.25rem (20px), SemiBold 600.
  - Заголовок задачи H3: 1.05rem (17px), Medium 600.
  - Описание задачи: 0.9rem (14.5px), Regular 400, line-height 1.5.
  - Метки и бейджи: 0.75rem–0.8125rem (12–13px), SemiBold 600, uppercase/letter-spacing 0.02em.
  - Числа статистики: 1.875rem (30px), Bold 700.

## Color roles
- **Фон страницы**: `#f8fafc` (с легким градиентом в `#eef2ff`).
- **Поверхности карточек (Card surfaces)**: `#ffffff`, мягкая глубина через `box-shadow: 0 4px 6px -1px rgba(0,0,0,0.06), 0 2px 4px -2px rgba(0,0,0,0.04)`.
- **Границы (Borders)**: `#e2e8f0` (разделители) и `#cbd5e1` (активные поля ввода).
- **Первичный акцент (Primary Indigo)**:
  - Основной: `#4f46e5`
  - Hover: `#4338ca`
  - Фоновый тинт: `#eef2ff`
- **Приоритеты**:
  - Высокий: Текст `#dc2626`, фон `#fef2f2`, рамка `#fecaca`
  - Средний: Текст `#d97706`, фон `#fffbeb`, рамка `#fde68a`
  - Низкий: Текст `#2563eb`, фон `#eff6ff`, рамка `#bfdbfe`
- **Статусы выполнения**:
  - Выполнено (Emerald): Текст `#059669`, фон `#ecfdf5`, рамка `#a7f3d0`
  - В процессе (Amber/Blue): Текст `#4f46e5`
  - Просрочено (Overdue Red): Текст `#b91c1c`, фон `#fee2e2`, пульсирующий маркер
  - Горит сегодня (Due Today Amber): Текст `#b45309`, фон `#fef3c7`

## Spacing / sizing
- Базовая сетка: 4px / 8px / 12px / 16px / 20px / 24px / 32px.
- Скругления: `border-radius: 12px` для карточек, `8px` для полей и кнопок, `9999px` для таблеток-бейджей (pill badges).
- Минимальная область клика: 44x44px на мобильных устройствах.

## Components & states
1. **Карточка задачи**:
   - Чекбокс: кастомный SVG с галочкой при активации, фокусом с outline-ring.
   - Заголовок: зачёркивание и приглушение цвета (`color: #94a3b8`) в выполненном состоянии.
   - Метаданные: бейдж приоритета, бейдж дедлайна с иконкой календаря и статусом (просрочено / сегодня / дата).
   - Действия: кнопка «Редактировать» (синий акцент при наведении) и «Удалить» (красный акцент при наведении).
2. **Фильтры-кнопки**:
   - Активный таб: сплошная заливка `#4f46e5` с белым текстом и контрастным чипом количества.
   - Неактивный: контурный стиль с мягким ховером.
3. **Модальное окно редактирования**:
   - Затемняющий фон с `backdrop-filter: blur(4px)`.
   - Кнопка закрытия `x`, кнопки «Отмена» и «Сохранить изменения».
4. **Всплывающие уведомления (Toasts)**:
   - Всплывают в правом верхнем углу (на мобильных — внизу по центру), автоматически исчезают через 3.5 секунды.

## Motion / interaction
- Плавные переходы `transition: all 0.2s cubic-bezier(0.4, 0, 0.2, 1)`.
- Анимация появления новой задачи (`slide-down` + `fade-in`).
- Анимация прогресс-бара с плавной интерполяцией ширины (`transition: width 0.4s ease`).
- Поддержка `prefers-reduced-motion`: отключение тяжелых трансформаций.

## Responsive behavior
- **Desktop (1024px+)**: Полноценный 2-колоночный интерфейс с плавающей боковой формой.
- **Tablet (768px – 1023px)**: 1 колонка, статистика в 2x2 грид, форма и задачи в вертикальном стеке.
- **Mobile (360px – 767px)**: Карточки статистики адаптируются в компактный 2x2 вид, панель фильтров превращается в скроллируемый или плотный ряд, действия над задачами всегда доступны и удобны для нажатия пальцем.

## Accessibility
- Все интерактивные элементы имеют явные `aria-label`, роли (`role="tab"`, `role="progressbar"`).
- Поддержка навигации клавиатурой (Tab, Shift+Tab, Enter, Space, Escape для закрытия модалки).
- Цветовой контраст текста к фону не менее 4.5:1 (соответствие WCAG AA).

## Originality / differentiation
В отличие от примитивных списков задач, «Менеджер учебных задач»:
1. Автоматически рассчитывает контекст учебного дедлайна («Просрочено!», «Сегодня!», «Завтра», «Осталось N дн.») и подсвечивает критические задания.
2. Содержит живой прогресс-бар успеваемости студента с расчётом процента выполненных задач.
3. Включает динамические счетчики на кнопках фильтров.
4. Оснащен встроенным механизмом предзагрузки учебных кейсов (курсовая, подготовка к коллоквиуму, лабораторная) для мгновенной демонстрации и тестирования.
