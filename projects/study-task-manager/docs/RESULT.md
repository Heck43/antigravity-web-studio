# Final result: «Менеджер учебных задач»

## Summary
Разработано веб-приложение для управления учебными задачами студентов и школьников. Приложение реализовано с использованием семантического HTML5, современного адаптивного CSS3 (Custom Properties, Flexbox, CSS Grid) и чистого модульного JavaScript (ES6+) без единой сторонней библиотеки.

## What was built
1. **Каталог файлов проекта**:
   - `project/index.html` — разметка интерфейса со всеми формами, модальным окном и секцией аналитики;
   - `project/style.css` — продуманная дизайн-система, адаптивные медиа-запросы, цветовые токены для приоритетов и статусов дедлайнов;
   - `project/script.js` — полнофункциональный JavaScript движок:
     - Создание, редактирование и удаление задач без перезагрузки страницы;
     - Чекбокс отметки выполнения с зачеркиванием текста и мгновенным обновлением аналитики;
     - 4 вкладки фильтрации («Все», «Активные», «Выполненные», «С высоким приоритетом») с интерактивными бейджами счетчиков на каждой кнопке;
     - Сортировка по сроку выполнения (ближайшие/дальние), по приоритету (высокий/низкий) и по дате добавления;
     - Живой поиск по названию и описанию задач с кнопкой мгновенного сброса;
     - Карточки статистики («Всего», «Выполнено», «В процессе») и анимированный прогресс-бар в %;
     - Надежное сохранение в `localStorage` с защитой от поврежденных данных;
     - Калькулятор дедлайнов с подсказками («Осталось X дн.», «Сегодня дедлайн!», «Просрочено на X дн.»);
     - Модальное окно редактирования с поддержкой клавиатуры (`Escape`, фокус);
     - Система всплывающих уведомлений (Toast);
     - Начальные учебные демо-данные и кнопка «Сбросить к примерам».

## Research and design inputs
- Исследованы лучшие решения современных сервисов продуктивности (Todoist, Linear, Notion, TickTick).
- Разработана оригинальная цветовая палитра: академический индиго (`#4f46e5`) как базовый акцент, изумрудный (`#10b981`) для выполненных задач, рубиновый (`#ef4444`) для срочных/высокоприоритетных и янтарный (`#f59e0b`) для средних.

## Verification evidence
- `node --check project/script.js` — синтаксис чистый.
- `tests/test-app.js` — 13/13 проверок пройдены (файлы, структура, CSS токены, фильтры, сортировка, статистика, localStorage).
- `tests/test-dom-lifecycle.js` — 100% прохождение всех браузерных сценариев в симуляции DOM (добавление, чекбокс, поиск, переключение табов, сериализация).
- Локальный веб-сервер отвечает статусом 200 на всех маршрутах (`http://localhost:8080/index.html` и `http://localhost:8080/project/index.html`).

## Known limitations
- Приложение работает на стороне клиента (Client-side SPA). Для синхронизации между разными устройствами требуется облачный бэкенд (выходит за рамки учебного задания).

## Run instructions
1. **Быстрый просмотр**:
   - Просто откройте файл `project/index.html` (или `index.html` в корне) в любом современном веб-браузере (Chrome, Edge, Firefox, Safari).
2. **Запуск через локальный сервер**:
   ```bash
   python -m http.server 8080
   ```
   и перейдите по адресу `http://localhost:8080/project/index.html`.
