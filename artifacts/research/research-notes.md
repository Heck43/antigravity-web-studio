# Исследование UI/UX решений для «Менеджера учебных задач»

## 1. Анализ интерфейсов современных планировщиков задач и трекеров для студентов
Были проанализированы паттерны ведущих инструментов (Todoist, Notion Student Dashboard, TickTick, Things 3, Google Tasks):

### Ключевые паттерны UX:
1. **Быстрая видимость дедлайнов**:
   - Студентам критически важно сразу видеть срочность задачи. Использование цветовых индикаторов для сроков:
     - Красный пульсирующий/выделенный бейдж для «Просрочено» и «Сегодня».
     - Оранжевый/желтый для «Завтра» и «В течение 3 дней».
     - Нейтральный для долгосрочных задач.
2. **Сегментированные фильтры со счетчиками**:
   - Вкладки фильтров («Все», «Активные», «Выполненные», «Высокий приоритет») должны содержать динамические счетчики количества задач в каждой категории. Это избавляет от необходимости переключаться вслепую.
3. **Статистика и ощущение прогресса (Gamification / Progress)**:
   - Студенты мотивируются визуальным прогрессом: шкала выполнения в процентах (0–100%) и карточки метрик (Всего, Выполнено, В процессе).
4. **Быстрое редактирование и модальное окно**:
   - Модальное диалоговое окно для редактирования с поддержкой клавиши Escape и клика вне области.
5. **Сохранение в localStorage с защитой**:
   - Валидация JSON, обработка поврежденных данных, версионирование схемы хранения и начальные демо-данные по учебным предметам (чтобы интерфейс не был пустым при первом открытии).

## 2. Цветовая палитра и типографика
- **Основной фон**: мягкий светлый градиент (`#f8fafc` / `#f1f5f9`), предотвращающий утомляемость глаз при учебе.
- **Акцентные цвета**:
  - Первичный (Indigo): `#4f46e5` / `#4338ca` — символизирует академичность, фокус и продуктивность.
  - Успех (Emerald): `#10b981` — для выполненных задач и высокого прогресса.
  - Внимание/Средний (Amber): `#f59e0b` — для средних приоритетов.
  - Срочность/Высокий (Rose/Red): `#ef4444` — для горящих дедлайнов и высокого приоритета.
- **Шрифт**: `Inter`, системный стек шрифтов (San Francisco, Segoe UI, Roboto) с высокой разборчивостью цифр и дат.

## 3. Архитектура и стандарты
- Чистый семантический HTML5 (`<header>`, `<main>`, `<aside>`, `<section>`, `<article>`, `<dialog>/<div role="dialog">`).
- CSS3: CSS Custom Properties (Variables), CSS Grid, Flexbox, плавные переходы (`transitions`), адаптивные медиа-запросы.
- Vanilla JavaScript: Модульный подход (State management, Storage, Event handlers, Render engine, Notification/Toast system). Без внешних зависимостей.
