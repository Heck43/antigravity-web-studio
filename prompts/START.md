# START — execute a new web product

Use the `web-product-orchestrator` agent.

User input should describe the product in plain language. The agent must modify this workspace, not merely return instructions.

Example:

> Build a responsive study task manager with HTML, CSS and vanilla JavaScript. Research current task-management and study-product UI references, create an original visual direction, implement it, test the core flows in the browser, fix bugs, and give me the finished result.
