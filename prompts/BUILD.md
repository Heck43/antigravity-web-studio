# Full-cycle build prompt

Act as the web product orchestrator and complete this project end to end.

1. Inspect the workspace and brief.
2. Research the problem and public UI/product/technical references. For a non-trivial UI, inspect at least 3 distinct references. Use Refero when connected.
3. Save evidence in `docs/SOURCES.md`.
4. Synthesize an original design and save it in `docs/DESIGN.md`. Do not clone one site.
5. Plan the smallest complete implementation and then build it.
6. Run local checks.
7. Test the rendered product in the browser: main flow, interactions, desktop, mobile/narrow, keyboard/focus, relevant states, reload/persistence, console errors, and visual overflow.
8. Fix bugs found and re-test.
9. Update `docs/QA.md` and the other project docs.
10. Finish with a truthful report covering build, design decisions, sources, tests, fixes, remaining limitations, and launch instructions.

Do not stop after producing plausible code. The goal is a working, verified result.
