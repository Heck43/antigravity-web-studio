# Ship Gate Prompt

Run the complete release gate for the current workspace.

Read the brief, task board, QA, visual, accessibility and performance reports. Verify evidence against acceptance criteria. Run any missing critical checks. Fix only verified in-scope defects, then re-test. Finish by updating `docs/SHIP_CHECKLIST.md` and `docs/RESULT.md` with a PASS or BLOCKED decision and concrete evidence.
